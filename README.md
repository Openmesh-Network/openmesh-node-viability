## Node-as-a-Service Viability Comparison

https://openmesh.network/naas
A graph showcasing the viability of running a web3 node hosted on a given provider.

## Commands

```
pnpm i
pnpm run dev
pnpm run build
pnpm run start
```

It is recommended to use pnpm, but you can also replace it with npm in the commands above.

### Generate

```
pnpm run generate
```
